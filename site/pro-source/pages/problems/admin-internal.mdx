## When it occurs

The console failed internally, or it replaced a failure that it cannot show safely. This includes 5xx errors from middleware, invalid codes or statuses from panels, and failed display projection.

## Client handling

Retry later. For an action, reload the target before you submit again. When a logger is configured, operators find the code, without request data, in the server log.
