## When it occurs

The handler ran, but its response exceeded `MaxResponseBytes` or could not be buffered. The default limit is 1 MiB. Execution could neither store nor return the response. A business effect may already have happened.

## Client handling

Do not repeat the operation automatically. Give `operation_ref` to an operator, who can find out whether the operation applied. A new key is safe only when `safe_new_key` is true.

## Server correction

Keep the handler's response under `MaxResponseBytes`. Check it together with the journal's `MaxResultBytes`. An oversized response does not prove the effect did not happen.
