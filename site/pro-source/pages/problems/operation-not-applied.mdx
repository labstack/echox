## When it occurs

The operation failed, and execution holds proof that none of its declared effects were applied. No result is stored for replay.

## Client handling

A new operation key is allowed only when `safe_new_key` is true. When false, do not use a new key. The same key keeps returning this answer.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Read safe_new_key explicitly. Only a true value permits a new operation key. A not-applied report must cover all sends without duplicate risk before another operation is allowed.
