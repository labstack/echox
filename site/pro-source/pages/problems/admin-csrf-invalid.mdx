## When it occurs

A POST that used ambient credentials, such as a cookie, did not carry a valid CSRF token. The token was missing, malformed or expired, or it belongs to another session.

## Client handling

Reload the page to get a fresh form and token, then submit again. API clients can send an explicit header credential, which needs no CSRF token.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Refresh the console controls in the current authenticated session. Verify the session binding and retained signing keys across instances. Submit the server-issued CSRF token through the console protocol.
