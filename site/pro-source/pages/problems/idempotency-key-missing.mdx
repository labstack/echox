## When it occurs

The request has no idempotency key. The header is `Idempotency-Key` unless the operation configures another name. Nothing was recorded, and the handler did not run.

## Client handling

Send one key for each logical operation, and reuse the same key and request when you retry that operation.

## Server correction

Have the client generate one key before the first attempt and retain it across retries. Generating a new key on each retry can run the operation twice.
