## When it occurs

The request has no idempotency key. The header is `Idempotency-Key` unless the operation configures another name. Nothing was recorded, and the handler did not run.

## Client handling

Send one key for each logical operation, and reuse the same key and request when you retry that operation.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Generate a stable operation key before the first attempt and retain it for retries. Send it in the configured key header. Generating a new key on each retry defeats binding.
