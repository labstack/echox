## When it occurs

The console or panel rejected a request parameter or action input. Causes include unknown or repeated parameters and malformed values. The console also uses this code when `Config.Middleware` returns HTTP 400.

## Client handling

Correct the parameters as the view or action documents them, then send the request again. Sending it unchanged gives the same result.

## Response fields

### Admin console

- `code` (string, always): The stable code above.
- `detail` (string, always): The console always sends `detail`. It is often empty and never contains the underlying error.
- `status` (integer, always): The HTTP status of the response.
- `title` (string, always): The HTTP status text, such as `Conflict`, unless the panel supplies its own title.
- `type` (string, always): The exact type URI above.

Headers:

- `Cache-Control` (always): `no-store`. The console sends it on every problem response, along with its usual security headers.

Notes:

- Fields are written in alphabetical order.
- The console rewrites every 404 response to `admin_not_found` with an empty `detail`.
