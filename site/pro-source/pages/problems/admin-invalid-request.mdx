## When it occurs

The console or panel rejected a request parameter or action input. Check for unknown parameters, repeated parameters and malformed values. Middleware that returns HTTP 400 is reported with this code too.

## Client handling

Correct the parameters as the view or action documents them, then send the request again. Sending it unchanged gives the same result.
