## When it occurs

A quota administration route rejected its input. Check for unknown or repeated query parameters and invalid periods. Send one JSON object of at most 64 KiB with `Content-Type: application/json`.

## Client handling

`detail` names the field, the reason and a fix. Correct the request and send it again; sending it unchanged gives the same result.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Correct the quota administration parameters, including the selected plan, partition and credit operation ID. This code is not a generic code for every application's HTTP 400.

## Response fields

### quota administration routes

- `code` (string, always): The stable code above.
- `type` (string, always): The exact type URI above.
- `title` (string, always): English title. Quota administration routes use their own titles for some codes.
- `status` (integer, always): The HTTP status of the response.
- `detail` (string, optional): Human-readable explanation, omitted when empty. Its wording is not a stable format.
- `violated-policies` (array, always): IDs of the limits involved: `[]` when there are none, never null. The hyphenated name is a legacy exception to the naming rule for new members.

Headers:

- `Cache-Control` (always): `no-store` on every administration response.

Notes:

- The members match the quota middleware's. The body ends with a newline. HEAD responses have no body.
- The title is `Invalid quota administration request`.
