## When it occurs

A quota administration route rejected its input. Causes include unknown or repeated query parameters, an invalid period, or a body other than one JSON object of at most 64 KiB sent as `application/json`.

## Client handling

`detail` names the field, the reason and a fix. Correct the request and send it again; sending it unchanged gives the same result.

## Server correction

Validate quota administration parameters, including plan, partition and credit operation ID. Do not use this code for your application's unrelated 400 responses.

## Response fields

### Quota administration routes

- `code` (string, always): The stable code above.
- `type` (string, always): The exact type URI above.
- `title` (string, always): English title. Quota administration routes use their own titles for some codes.
- `status` (integer, always): The HTTP status of the response.
- `detail` (string, optional): Human-readable explanation, omitted when empty. Its wording is not a stable format.
- `violated-policies` (array, always): IDs of the limits involved: `[]` when there are none, never null.

Headers:

- `Cache-Control` (always): `no-store` on every administration response.

Notes:

- Quota administration rejected the request.
