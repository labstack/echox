## When it occurs

The idempotency key header is invalid. It must be one field line of at most 300 bytes, containing one RFC 8941 string, such as `"order-42"`, or one token. Execution rejects lists and repeated lines. Nothing was recorded, and the handler did not run.

## Client handling

Send the key once as a quoted string or token. Keep that value when retrying the operation.

## Server correction

Check that clients and proxies preserve one `Idempotency-Key` field line. Reject duplicate lines, lists and unsupported syntax.
