## When it occurs

The idempotency key header is not valid. Send exactly one field line of at most 300 bytes. It must contain one RFC 8941 string, such as `"order-42"`, or one token. Lists and repeated lines are rejected. Nothing was recorded, and the handler did not run.

## Client handling

Send the key once as a quoted string or token. Keep that value when retrying the operation.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Send exactly one Idempotency-Key field line, at most 300 bytes, using an accepted item string or bare token without parameters. Remove duplicate lines, lists and unsupported syntax.
