## When it occurs

An action commit lacked its required confirmation: the typed confirmation text did not match, or a required acknowledgement was missing.

## Client handling

Type the confirmation text exactly as the preview shows it, accept every required acknowledgement, and submit again.

## Server correction

Check the action's confirmation text and required acknowledgements in its panel descriptor. Keep those checks enabled for destructive actions.

Headers:

Notes:
