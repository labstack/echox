## When it occurs

The console could not durably record the audit intent of an action, so it did not run the action. Either no audit sink is configured and unaudited writes are not allowed, or the sink failed.

## Client handling

No change was made. Retry later with the same `action_id` and input. Operators should check the audit sink.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Restore the configured audit sink's ability to accept an intent record. Check capacity, permissions and its recording deadline. The refused attempt performed no mutation; retain the original action ID when retrying.
