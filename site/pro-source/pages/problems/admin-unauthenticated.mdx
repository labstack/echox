## When it occurs

The console could not authenticate the request: `Config.Authenticate` failed or returned an invalid principal, or middleware returned HTTP 401.

## Client handling

Sign in again or send valid credentials. When the response carries a `WWW-Authenticate` challenge, follow it.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Restore a valid application login or bearer credential. Verify that Authenticate maps the validated ID into a nonempty principal ID and the correct session or header-credential binding.

Headers:

Notes:
