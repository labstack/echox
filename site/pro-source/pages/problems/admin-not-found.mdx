## When it occurs

The requested panel, view or target does not exist or is not available to the signed-in principal. Both cases return the same response with an empty `detail`, so the response does not tell them apart.

## Client handling

Check the path and the target parameters. If you expect access, ask the console's administrator; the response itself gives no further reason.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Check the mounted prefix, enabled panel and authorized target. The shell deliberately uses the same 404 representation for missing or undisclosed resources, so do not infer target existence from this response.
