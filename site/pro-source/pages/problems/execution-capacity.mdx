## When it occurs

Execution storage reached a capacity limit, such as the tenant's limit on unresolved operations or the namespace's byte budget. The handler did not run for this request.

## Client handling

Retry later with the same key and request, after the `Retry-After` delay. Persistent capacity errors need an operator to resolve uncertain operations or adjust limits.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Inspect namespace limits on records, bytes and unresolved tenants. Remove eligible completed records according to retention policy. Resolve uncertain operations using verified provider records. They do not expire to free capacity.
