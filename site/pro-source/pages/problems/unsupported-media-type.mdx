## When it occurs

The application's request binding does not support the request's Content-Type. The application returns this code only where it knows the binder refused the media type.

## Client handling

Send the body with a media type that the API documents, for example `application/json`.

## Server correction

Keep documented media types aligned with the binder and validator. Clients must set a matching `Content-Type` before retrying.
