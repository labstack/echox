| 415 | Unsupported Media Type |

## When it occurs

The application's request binding does not support the request's Content-Type. The application returns this code only where it knows the binder refused the media type.

## Client handling

Send the body with a media type that the API documents, for example application/json.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

HTTP 415:

```json file=site/pro-source/examples/problems/unsupported-media-type-415.json
```

## How to fix

Send a media type declared by the API and a body encoded for it. Correct Content-Type before retrying. A response body cannot establish a new supported request format.
