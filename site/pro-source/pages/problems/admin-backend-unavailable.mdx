## When it occurs

A built-in panel failed to read its quota store, execution store or Stripe export status. The backend error stays internal.

## Client handling

Retry later. If the error persists, operators should check the backend's health and the server logs.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Inspect the panel backend and restore its connection, permissions or capacity. For a failed mutation, reload the target before deciding the next action. A backend error alone does not prove rollback.
