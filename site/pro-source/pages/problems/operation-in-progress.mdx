## When it occurs

Another attempt of the same operation holds a live lease, so this request did not run the handler.

## Client handling

Retry later with the same key and the same request, after the `Retry-After` delay when present. Do not switch to a new key: that could run the operation twice.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Wait for the live holder using Retry-After, then query or retry the same operation key. Do not start the same business operation under another key while the first holder can still act.
