## When it occurs

The application refused the request because authentication failed or was missing. It returns this code only for a refusal it knows is an authentication failure, and keeps its own `WWW-Authenticate` challenge.

## Client handling

Authenticate as the `WWW-Authenticate` challenge describes, then retry.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Supply a current supported credential and inspect WWW-Authenticate. Verify API-key revocation and pepper versions or bearer issuer, audience, signature and expiry. Never log the rejected credential.
