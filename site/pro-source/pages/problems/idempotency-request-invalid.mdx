## When it occurs

Execution could not fingerprint the request, so it did not record it under the key. Status 413 means the body exceeds `MaxFingerprintBytes` (default 1 MiB). Other fingerprinting failures return 400. Causes include malformed input, unreadable bodies, cancellation and custom fingerprint callback failures. Nothing was recorded, and the handler did not run.

## Client handling

For 413, send a smaller body. For 400, check that the request is well formed before retrying. An interrupted body read can also cause this response. You can keep the same key, because nothing was recorded.
