## When it occurs

Fingerprinting the request failed, so it was not bound to its key. Status 413 means the body exceeds `MaxFingerprintBytes` (default 1 MiB). Other fingerprinting failures return 400. Causes include malformed input, unreadable bodies, cancellation and custom fingerprint callback failures. Nothing was recorded, and the handler did not run.

## Client handling

For 413, send a smaller body. For 400, check that the request is well formed before retrying. An interrupted body read can also cause this response. You can keep the same key, because nothing was recorded.

## How to fix

For HTTP 400, correct malformed query, content type or JSON input. For HTTP 413, reduce the fingerprinted body to MaxFingerprintBytes. The preparation refusal does not bind the malformed request.
