## When it occurs

The operation finished, but its stored response passed its retention period. The record and its state may still exist; only the response bytes are gone.

## Client handling

The original response cannot be replayed. Use `operation_state` and `operation_ref` to learn the outcome, or ask an operator. This answer is not proof that no effect happened. A new key is safe only when `safe_new_key` is true.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Use an authorized application lookup for the completed operation's business result. Publish the configured result-retention window. The retained operation key prevents rerunning work after its response bytes expire.
