## When it occurs

The operation finished, but its stored response passed its retention period. The record and its state may still exist; only the response bytes are gone.

## Client handling

The original response cannot be replayed. Use `operation_state` and `operation_ref` to learn the outcome, or ask an operator. This answer is not proof that no effect happened. A new key is safe only when `safe_new_key` is true.

## Server correction

Provide an authorized application API for looking up the business result. Tell clients the `Policy.ResultRetention` window (24 hours by default). The retained key prevents rerunning work after the response expires.
