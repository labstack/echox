## When it occurs

The result of the operation is unknown. An external send started without a recorded outcome before lease expiry, or the handler reported an uncertain outcome. The effect may or may not have happened.

## Client handling

Do not retry automatically, with either the same key or a new one. Report `operation_ref` to an authorized operator, who can reconcile or resolve the operation. The reference is shown only after the request passed the operation's replay authorization.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Send the reference to an authorized operator. Reconcile every possibly applied send with authoritative provider records, or record an explicit reviewed resolution. Neither timeout nor a missing reply proves that no send applied.
