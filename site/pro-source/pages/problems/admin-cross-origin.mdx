## When it occurs

The request failed the console's origin checks. Every request is checked against the configured origins, and POST requests also pass Go's cross-origin protection.

## Client handling

Open the console from its configured origin, and do not submit console forms from other sites. Include the console's public origin in `Config.Origins`.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Use an allowed console origin. Configure exact deployed origins and the public path at mount time. Ensure outer middleware passes console requests into the console's own security wrapper.
