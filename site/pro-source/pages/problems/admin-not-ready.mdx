## When it occurs

The OpenAPI panel has no bound report yet. Until `Bind` succeeds with the report of a successful `Mount`, every view of that panel returns this code after authorization.

## Client handling

Retrying does not help until the application binds a report. Operators should bind the `*openapi.Report` returned by a successful `openapi.MiddlewareConfig.Mount`.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Complete the panel's required initialization or readiness checks before using the view or action. Keep an unavailable observation distinct from a healthy backend. Inspect the backend without bypassing authorization.
