## When it occurs

The operation finished without a stored response. Storage pressure or failed redaction can cause a response to be omitted or withheld.

## Client handling

A withheld or omitted result is not proof that no effect happened. Use `operation_state` and `operation_ref`, or ask an operator. A new key is safe only when `safe_new_key` is true.
