## When it occurs

The application refused the request under its authorization policy. It returns this code only for a refusal it knows is an authorization decision.

## Client handling

Do not retry with the same credentials. Ask for the required permission, or use an account that has it.

## Example response

The package may omit diagnostic text or return it empty. Operation references do not grant access. Custom handlers can replace the body.

## How to fix

Correct the verified scope, membership or resource grant that refused access. For a tenant mismatch, select an allowed tenant and a resource owned by it. Do not retry an unchanged forbidden request automatically.
