## Required fields

- `JournalConfig`: `Namespace`, `Store` and `Policies`.
- `MiddlewareConfig`: a constructed `Journal`, an `Operation`, and the `Identity` and `ReplayCheck` callbacks.
- Every instance: matching namespace limits and `BudgetShards`, which the store saves.
- Separate response limits: `MiddlewareConfig.MaxResponseBytes` for live HTTP output and `JournalConfig.MaxResultBytes` for stored results.

Uncertain operations never expire; an operator must resolve them.

## HTTP and retention limits

| Setting | Default or limit |
| --- | --- |
| `MiddlewareConfig.Header` | `Idempotency-Key` |
| `ParseKey` | One field line, at most 300 bytes; RFC 8941 Item String without parameters or a bare token |
| `MiddlewareConfig.MaxFingerprintBytes` | 1 MiB by default; at most 8 MiB |
| `MiddlewareConfig.MaxResponseBytes` | 1 MiB by default; at most 8 MiB |
| `JournalConfig.MaxResultBytes` | 64 KiB by default; at most 1 MiB |
| `Policy.ResultRetention` | 24 hours by default |
| `Policy.KeyRetention` | Seven days by default; unresolved records do not expire automatically |

Keep the store open until requests, recovery calls and the scheduler have stopped.

## Error types

Business failures use `*execution.FailureError`; uncertain external effects
use `*execution.AmbiguityError`. The execution mode type is `execution.Mode`.
