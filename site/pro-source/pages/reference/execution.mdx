This reference describes `echo.labstack.com/pro` v0.1.0. [Install the module](/pro/install/) once; subpackages use that same version. The [package explanation](/pro/execution/) describes behavior and limits. The [task guide](/pro/guides/execution/) contains source-backed examples and route wiring.

## Defaults

Journal namespace, store and policies are required. The HTTP adapter also requires `Identity` and `ReplayCheck` callbacks. Namespace caps and shard count are persisted and must agree across instances. `MaxResponseBytes` and the journal's `MaxResultBytes` are independent bounds. Uncertain bindings do not expire through terminal retention.

The tables list each field's Go type, source comment and default or requirement.
A shared comment may describe several fields. Use the enclosing type's instructions when a field has no stated default.
The tables do not infer constructor defaults from Go zero values.

## HTTP and retention limits

| Setting | Default or limit |
| --- | --- |
| Key header | `Idempotency-Key` |
| Key syntax | One field line, at most 300 bytes; RFC 8941 Item String without parameters or a bare token |
| Request fingerprint | 1 MiB by default; at most 8 MiB |
| Live HTTP response | 1 MiB by default; at most 8 MiB |
| Stored result | 64 KiB by default; at most 1 MiB |
| Result retention | 24 hours by default |
| Operation key retention | Seven days by default; unresolved records do not expire automatically |
