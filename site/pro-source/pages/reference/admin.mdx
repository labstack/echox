This reference describes `echo.labstack.com/pro` v0.1.0. [Install the module](/pro/install/) once; subpackages use that same version. The [package explanation](/pro/admin/) describes behavior and limits. The [task guide](/pro/guides/admin/) contains source-backed examples and route wiring.

## Defaults

`Panels` and `Authenticate` are required. Viewer is the default authenticated role. Write actions need separate role, scope, confirmation and audit policy. `PublicPath` defaults to the mount prefix. Empty `Theme.Mode` follows the system. The caller owns each panel's backend, authentication lifecycle and any configured audit sink.

The tables list each field's Go type, source comment and default or requirement.
A shared comment may describe several fields. Use the enclosing type's instructions when a field has no stated default.
The tables do not infer constructor defaults from Go zero values.

## Read and token limits

| Setting | Default or limit |
| --- | --- |
| Request timeout | Ten seconds; range one millisecond–one minute; includes middleware |
| Expensive concurrent reads | Two; range 1–64 |
| Cursor lifetime | 15 minutes |
| CSRF token lifetime | One hour |

Saturation rejects the console request with a classified problem response.
