## Required fields

- `SchemaConfig.Keys`: HMAC keys for the default storage policy; `Policy.AllowMaskFallback` permits masking instead.
- `MemoryStoreConfig.Capacity`: positive event and byte capacities; a full store never evicts older events.
- `auditpg`: caller-owned pools, a NOLOGIN deployment owner and four distinct runtime roles (`auditpg.Roles`).

A reader pagination cursor does not grant access; authorize every read and continuation.

## Event and read limits

| Setting | Default or limit |
| --- | --- |
| `SchemaConfig.Fields` | At most 256 |
| `Event.Action` | Two to eight dot-separated segments, at most 128 bytes. The `audit.` prefix is reserved. |
| `DenialConfig.Timeout` / `MaxInFlight` | 500 ms recording timeout and 64 concurrent calls by default |
| `auditpg.SchemaConfig.Schema` | `public` by default |
| `auditpg.SchemaConfig.Timeout` | Five seconds by default |
| `auditpg.SchemaConfig.MigrateTimeout` | One minute by default |
| `QueryRequest.Limit` | 50 entries by default; at most 100 |

Keep pools and stores open until requests, relay work and retention work have stopped.
