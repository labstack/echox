## Defaults

`SchemaConfig` at zero selects the redact storage policy, which requires HMAC keys unless mask fallback is explicit. A memory store requires capacity. It never evicts audit events to record new ones. PostgreSQL stores require caller-owned pools and validated separate roles. Reader continuations do not grant access.

The tables list each field's Go type, source comment and default or requirement.
A shared comment may describe several fields. Use the enclosing type's instructions when a field has no stated default.
The tables do not infer constructor defaults from Go zero values.

## Event and read limits

| Setting | Default or limit |
| --- | --- |
| Registered metadata fields | At most 256 |
| Action names | Two–eight dot-separated segments; at most 128 bytes; `audit.` reserved |
| Detached denial recording | 500 ms by default; at most 64 in-flight writes by default |
| PostgreSQL schema | `public` by default |
| PostgreSQL operation timeout | Five seconds by default |
| Migration timeout | One minute by default |
| Query page | 50 entries by default; at most 100 |
