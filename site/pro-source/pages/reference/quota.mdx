This reference describes `echo.labstack.com/pro` v0.1.0. [Install the module](/pro/install/) once; subpackages use that same version. The [package explanation](/pro/quota/) describes behavior and limits. The [task guide](/pro/guides/quota/) contains source-backed examples and route wiring.

## Defaults

`Config.Store` and `Plans` are required. Middleware needs an `Identity` callback using verified application data. One plan selects itself. Multiple plans require `Plan`. Billing periods require `Period`. Hooks, fallback and outbox behavior are documented with their fields.
If you leave a telemetry callback nil, the package does not call it. Redis constructors validate options without connecting. Your application closes the client.

The tables list each field's Go type, source comment and default or requirement.
A shared comment may describe several fields. Use the enclosing type's instructions when a field has no stated default.
The tables do not infer constructor defaults from Go zero values.

## Plan and store limits

| Setting | Default or limit |
| --- | --- |
| Limits in a plan | 1–16 |
| Limit IDs and meters | `[a-z0-9][a-z0-9_]{0,31}` |
| Refill burst | Refill amount by default |
| Concurrent lease | Five minutes by default |
| Subject parts and operations | At most 256 bytes each |
| Remote store timeout | 25 ms by default; caller cancellation can end it sooner |
| Denial cache | Off by default; at most ten seconds and never longer than the retry delay |
