## Required fields

- `Config.Store` and `Config.Plans`: a store and at least one plan.
- `MiddlewareConfig.Identity`: the paying subject from verified application data.
- `MiddlewareConfig.Plan`: required with several plans; nil selects the only configured plan.
- `MiddlewareConfig.Period`: required for billing-period limits.

Redis constructors check options without connecting; your application owns and closes the client.

## Plan and store limits

| Setting | Default or limit |
| --- | --- |
| `Plan.Limits` | 1–16 |
| `LimitInfo.ID` / `LimitInfo.Meter` | `[a-z0-9][a-z0-9_]{0,31}` |
| `Limit.Burst()` | Equals the refill amount unless set |
| `Limit.Lease()` | Five minutes by default |
| `Identity` / operation strings | At most 256 bytes each |
| `Config.StoreTimeout` | 25 ms by default; caller cancellation can end it sooner |
| `Config.DenyCache` | Off by default; at most ten seconds and never longer than the retry delay |

Call `Limiter.Close` before closing its store or Redis client.
