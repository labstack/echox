El middleware JWT proporciona autenticación JSON Web Token (JWT). Vive en un módulo separado:
[github.com/labstack/echo-jwt](https://github.com/labstack/echo-jwt).

Comportamiento:

- Para un token válido, establece el usuario en el contexto y llama al siguiente handler.
- Para un token inválido, envía una response `401 Unauthorized`.
- Para un header `Authorization` ausente o inválido, envía una response `400 Bad Request`.

## Dependencias

```go
import "github.com/labstack/echo-jwt/v5"
```

## Uso

```go
e.Use(echojwt.JWT([]byte("secret")))
```

## Configuración personalizada

```go
e.Use(echojwt.WithConfig(echojwt.Config{
	SigningKey: []byte("secret"),
}))
```
