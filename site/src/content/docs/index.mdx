    <FeatureCard title="Optimized Router" icon="rocket">Radix-tree routing with zero dynamic allocation and smart route prioritization.</FeatureCard>
    <FeatureCard title="Batteries-included Middleware" icon="setting">CORS, JWT, rate-limit, gzip, recover, request logging — 25+ built in.</FeatureCard>
    <FeatureCard title="Data Binding" icon="document">Bind JSON, XML, form, query &amp; path params into typed structs, with validation.</FeatureCard>
    <FeatureCard title="Automatic TLS" icon="padlock">HTTPS out of the box via Let's Encrypt, plus HTTP/2 support.</FeatureCard>
    <FeatureCard title="Extensible" icon="puzzle">Composable middleware and a clean, minimal interface for total control.</FeatureCard>
    <FeatureCard title="Templates" icon="window">Plug in any Go template engine for fast, flexible HTML rendering.</FeatureCard>

<div class="echo-h"><span class="ey">Get Started</span><h2>A running server in three steps.</h2></div>

<div class="echo-steps">
  <Steps>
    <ol>
      <li>
        <h3>Install</h3>
        <p>Create a module and add Echo.</p>
        <Code code={'go mod init myapp\ngo get github.com/labstack/echo/v5'} lang="bash" frame="none" wrap />
      </li>
      <li>
        <h3>Write</h3>
        <p>Save the <a href="/cookbook/hello-world/">Hello World server</a> as <code>server.go</code>.</p>

        ```go file=cookbook/hello-world/server.go frame="none" wrap
        ```

      </li>
      <li>
        <h3>Run</h3>
        <p>Fetch dependencies and start serving on port 1323.</p>
        <Code code={'go mod tidy\ngo run server.go'} lang="bash" frame="none" wrap />
      </li>
    </ol>
  </Steps>
</div>
