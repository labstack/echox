<div class="echo-h"><h2>A running server in three steps.</h2></div>

<div class="echo-steps">
  <Steps>
    <ol>
      <li>
        <h3>Install</h3>
        <p>Create a module and add Echo.</p>
        <Code code={'go mod init myapp\ngo get github.com/labstack/echo/v5'} lang="bash" frame="none" wrap />
      </li>
      <li>
        <h3>Write</h3>
        <p>The core of <code>server.go</code>. Copy the <a href="/cookbook/hello-world/">full Hello World example</a> for the imports and <code>main</code>.</p>

        ```go file=cookbook/hello-world/server.go#hero frame="none" wrap
        ```

      </li>
      <li>
        <h3>Run</h3>
        <p>Fetch dependencies and start serving on port 1323.</p>
        <Code code={'go mod tidy\ngo run server.go'} lang="bash" frame="none" wrap />
      </li>
    </ol>
  </Steps>
</div>
