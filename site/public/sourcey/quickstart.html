Get started

Quickstart

Install Echo v5, run your first Hello World server, and learn the core concepts — Echo instance, routes, handlers, Start.

Echo v5 requires Go 1.25 or higher. If you need to install or upgrade Go, visit the official Go download page.

Install

Create a new directory for your project, initialize Go modules, then install Echo:

go mod init myapp
go get github.com/labstack/echo/v5

Hello, World!

package main

import (
	"log/slog"
	"net/http"

	"github.com/labstack/echo/v5"
	"github.com/labstack/echo/v5/middleware"
)

func main() {
	e := echo.New()

	e.Use(middleware.RequestLogger()) // log requests with log/slog
	e.Use(middleware.Recover())       // recover from panics and return an error

	e.GET("/", hello)

	if err := e.Start(":8080"); err != nil {
		slog.Error("failed to start server", "error", err)
	}
}

func hello(c *echo.Context) error {
	return c.String(http.StatusOK, "Hello, World!")
}

Run it and send a request:

$ go run .
$ curl http://localhost:8080/
Hello, World!

e.Start shuts the server down gracefully on Ctrl+C.

Core concepts

This simple server introduces the core concepts of Echo:

  • Echo instance — echo.New() creates the application. echo.NewWithConfig takes a Config to tune it (see Config in the Go API).
  • Routes — e.GET, e.POST, e.PUT, e.DELETE, and friends register handlers for a method + path. Paths support parameters (:id) and wildcards (*) — see Routing and context.
  • Handlers — in v5 a handler takes *echo.Context (a pointer to the concrete Context struct) and returns an error. c.String, c.JSON, c.HTML, and c.File write the response — see Context and responses.
  • Middleware — e.Use registers handlers that run after routing; e.Pre registers handlers that run before routing — see Middleware.
  • Start — e.Start(":8080") starts the server. It returns only errors that are not http.ErrServerClosed, so a graceful shutdown on Ctrl+C is not an error.
